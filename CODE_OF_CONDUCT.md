# Code of Conduct

Rustalis is an open-source systems project. Contributors are expected to be respectful, constructive, and technically rigorous.

Unacceptable behavior includes harassment, discrimination, personal attacks, deliberate disruption, and publishing private information.

Maintainers may remove comments, reject contributions, or restrict participation when these standards are violated.

For security vulnerabilities, use the process in [SECURITY.md](SECURITY.md) rather than public issue reports.
